# Internship Assignments

This repository contains weekly assignments completed during my data science internship. Each week's work is organized into dedicated folders for better structure and navigation.

## Repository Structure

The repository follows a week-based organization system:

```
Internship/
├── week1/
│   └── main2.ipynb
├── README.md
└── [future weekly folders]
```

Each week's folder contains the assignments, code, and related materials for that specific week.

## Weekly Assignments

### Week 1: Titanic Dataset - Data Cleaning and Preprocessing

**File:** `week1/main2.ipynb`

**Description:**
This assignment focuses on data cleaning and preprocessing techniques using the famous Titanic dataset. The notebook covers:

- **Data Loading:** Importing the Titanic dataset using pandas
- **Data Exploration:** Initial analysis of the dataset structure
- **Handling Missing Values:** Techniques for dealing with incomplete data
- **Label Encoding:** Converting categorical variables into numerical format using LabelEncoder
- **One-Hot Encoding:** Creating binary columns for categorical features using OneHotEncoder
- **Data Visualization:** Using matplotlib and seaborn for visual analysis

**Key Skills Demonstrated:**
- Data cleaning and preprocessing
- Handling missing data
- Feature engineering through encoding techniques
- Python libraries: pandas, matplotlib, seaborn, scikit-learn

## Getting Started

To run the notebooks in this repository:

1. Clone the repository:
   ```bash
   git clone https://github.com/GayatriDarwade/Internship.git
   cd Internship
   ```

2. Install required dependencies:
   ```bash
   pip install pandas matplotlib seaborn scikit-learn jupyter
   ```

3. Launch Jupyter Notebook:
   ```bash
   jupyter notebook
   ```

4. Navigate to the desired week's folder and open the notebook.
